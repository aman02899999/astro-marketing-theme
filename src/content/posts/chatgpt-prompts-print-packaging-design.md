Print and packaging design is where brand identity becomes tangible. These prompts help you brief designers effectively, write copy that fits tight spaces, plan layouts that meet print production requirements, and create packaging that stands out on shelf.

## Packaging Design Prompts

### Prompt 1: Packaging Design Brief

```
Create a packaging design brief for:

Product: [name and description]
Product category: [food / beverage / cosmetics / consumer goods / etc.]
Package type: [box / bottle / pouch / tube / jar / bag / etc.]
Package dimensions: [approximate or required dimensions]
Target customer: [detailed description]
Retail environment: [where sold — Amazon / grocery shelf / boutique / pharmacy]
Brand personality: [adjectives describing the brand]
Competitors' packaging: [describe how they look]
Our differentiation: [what should make our packaging stand out]

Brief includes:
1. Design direction (the visual concept in words)
2. Color palette (primary + secondary + accent)
3. Typography direction (font personality, not specific fonts)
4. Imagery direction (photography / illustration / pattern / abstract)
5. Hierarchy of information (what appears most prominently on each panel)
6. Copy requirements (what text must appear where)
7. Technical requirements (barcode placement, recycling symbols, certifications)
8. Mood board direction (3 reference aesthetics)
```

### Prompt 2: Packaging Copy Writer

```
Write copy for all panels of a [product type] package:

Product: [name]
Key benefit: [primary promise]
Secondary benefits: [list 3–5]
Ingredients or materials: [list]
Brand voice: [adjectives]
Target customer: [description]
Package panels available:
  Front: [dimensions and what must appear — logo, name, variant, key claim]
  Back: [dimensions — description, directions, full ingredients]
  Side 1: [available space]
  Side 2: [available space]

Write copy for each panel:
Front: [product name + hero claim + variant name — maximize visual impact, minimize words]
Back: [2–3 sentence product story + directions/usage + full ingredient list format]
Sides: [secondary benefits + brand story element]

Rules: every word earns its place. No filler claims. Specific beats vague.
```

## Print Design Prompts

### Prompt 3: Print Collateral System

```
Plan a print collateral system for:

Brand: [name and description]
Campaign or purpose: [trade show / product launch / retail / B2B sales]
Collateral pieces needed: [list — business cards, flyers, brochures, banners, etc.]
Brand guidelines I have: [describe your existing brand elements]
Audience: [who receives these materials]

For each collateral piece:
1. Size and format (standard or custom)
2. Content hierarchy (what information appears in what order)
3. Copy for each section (headline, body, CTA)
4. Design direction notes (how brand guidelines apply to this format)
5. Print specs to communicate to the designer (bleed, safe zones, color mode)
6. Quantity and distribution plan

Also: which pieces work as a system (matching visual language across items).
```

### Prompt 4: Brochure Copy and Structure

```
Write copy and structure for a [type] brochure:

Brand: [name]
Brochure format: [trifold / gatefold / saddle-stitch / Z-fold]
Purpose: [what this brochure does — sells / educates / introduces / supports sales]
Audience: [who reads it]
Key message: [one sentence — what they must take away]
Supporting points: [list 5–7]
Call to action: [what you want them to do]

Panel-by-panel plan:

COVER:
- Headline: [benefit-led, under 8 words]
- Subheadline
- Visual direction

INSIDE PANELS (2–3 panels depending on format):
- Panel 1: [Problem or opportunity statement]
- Panel 2: [Solution + proof]
- Panel 3: [Product/service details]

BACK PANEL:
- About us (3 sentences)
- Contact information
- CTA

Write the complete copy for all panels.
```

## Production Specification Prompts

### Prompt 5: Print Production Checklist

```
Generate a print production checklist for:

Project type: [packaging / brochure / banner / poster / business cards]
Printing method: [offset / digital / flexographic / screen printing]
Substrate: [paper / cardboard / vinyl / fabric / etc.]
Color requirements: [CMYK / Pantone / RGB for digital proof]
Finishing: [lamination / embossing / spot UV / die-cut / etc.]
Quantity: [X units]
Turnaround: [X days]

Checklist covers:
1. File setup (bleed, safe zone, resolution — for this specific project)
2. Color mode verification
3. Font embedding / outline conversion
4. Image resolution requirements at final print size
5. Proof types to request (soft proof / hard proof / press check)
6. Pre-flight checklist items
7. Questions to ask the printer before submitting files
8. Approval sign-off requirements

Format as a checklist I can send to a designer.
```

## Frequently Asked Questions

### What resolution do images need to be for print?

Minimum 300 DPI (dots per inch) at the final print size for high-quality print. For large format (banners, posters viewed from distance), 150 DPI is often acceptable. For packaging, some printers require 400 DPI for photographic elements. Always check with your specific printer before finalizing files.

### What's the difference between CMYK and RGB for print?

RGB (Red, Green, Blue) is for screens. CMYK (Cyan, Magenta, Yellow, Black) is for print. Always design print files in CMYK from the start. Converting from RGB to CMYK at the end changes colors (especially vibrant blues and greens). For brand colors that must match exactly, specify Pantone (PMS) colors and request color matching from your printer.

### How much bleed should I include in print files?

Standard bleed is 0.125 inches (3mm) on all sides. Large format printing may require 0.25 inches. Bleed extends your design beyond the trim edge so that if the cut shifts slightly, there's no white edge showing. Safe zone (keep all important content inside) is typically 0.125 inches inside the trim line.

### When should I use Pantone vs CMYK?

Pantone (PMS) for: brand colors that must be consistent across multiple print runs and materials, corporate identity, packaging where color accuracy is critical. CMYK for: photographs, designs with many colors, situations where color matching has some tolerance. Pantone is more expensive (requires an additional press pass) but guarantees exact color reproduction.

### How do I brief a printer I've never worked with before?

Provide: final file format (PDF/X-1a is safest), dimensions with and without bleed, color mode (CMYK or Pantone), paper stock requirements, finishing specifications, quantity, and turnaround date. Ask for: a hard proof (physical print) before full production run for any quantity over 100 units, and confirm their file requirements before submitting. Prompt 5 covers everything you need to communicate.
