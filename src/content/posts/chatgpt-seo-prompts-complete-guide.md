SEO has never been more competitive — or more AI-assisted. Marketers using ChatGPT for SEO are producing more content, finding better keywords, and optimizing faster than those who don't.

This guide gives you **30+ proven ChatGPT SEO prompts** for keyword research, content creation, on-page optimization, technical audits, and link building.

> **Note:** These prompts work with GPT-4, Claude, and Gemini. Combine them with Ahrefs, SEMrush, or Google Search Console for best results. ChatGPT can't replace real search data — but it supercharges everything around it.

## Keyword Research Prompts

### Prompt 1: Seed Keyword Expansion

```
Act as an SEO expert. I'm targeting the keyword: "[your main keyword]"
My website is about: [your niche]
My target audience: [who reads your site]

Generate:
1. 20 long-tail variations (3–5 words each)
2. 10 question-based keywords (who, what, how, why)
3. 5 comparison keywords ("[keyword] vs [alternative]")
4. 5 "best of" keywords ("best [keyword] for [use case]")

For each, estimate:
- Search intent (informational / commercial / transactional)
- Competition (low / medium / high)
- Best content format to rank (listicle / guide / tool / comparison)
```

---

### Prompt 2: Keyword Clustering

```
Group these keywords into topic clusters for my website:
[paste your keyword list]

For each cluster:
1. Name the cluster (pillar topic)
2. Identify the primary keyword
3. List supporting cluster keywords
4. Suggest one pillar page + 3–5 cluster pages
5. Identify internal linking opportunities
```

---

### Prompt 3: SERP Intent Analysis

```
Analyze the search intent for: "[keyword]"

Tell me:
1. Primary intent (informational / navigational / commercial / transactional)
2. Content format most likely to rank (listicle, how-to, review, tool, comparison)
3. Estimated word count of top-ranking content
4. Key subtopics that must be covered to compete
5. E-E-A-T signals I should include
6. Featured snippet opportunity (yes/no, and format)
```

## On-Page SEO Prompts

### Prompt 4: SEO Title & Meta Description

```
Write 5 SEO-optimized title tags and meta descriptions:
Target keyword: "[keyword]"
Page type: [blog post / product page / landing page]

Requirements:
- Title: 50–60 characters, keyword near the start
- Meta description: 150–160 characters, keyword included, ends with a CTA
- Each variation takes a different angle or emotional hook
- Include power words where natural
```

---

### Prompt 5: Full SEO Content Brief

```
Create a detailed SEO content brief:
Primary keyword: "[keyword]"
Secondary keywords: [list 3–5]
Target word count: [1,500–2,500]
Content type: [blog post / guide / listicle]

Include:
1. Recommended H1 title (not the same as meta title)
2. URL slug suggestion
3. Introduction angle / hook
4. Complete H2 and H3 outline with notes per section
5. Internal linking placeholders
6. Types of external sources to cite
7. Schema markup recommendation
8. Call-to-action options
```

---

### Prompt 6: Optimize Existing Content

```
I have an article targeting "[keyword]" currently at position [rank or "not ranking"].

Article content (key sections):
[paste your article or key sections]

Suggest optimizations for:
1. Title tag and meta description
2. Missing subtopics (content gaps vs top results)
3. Keyword density and placement
4. Internal linking opportunities
5. Featured snippet optimization
6. Schema markup to add
7. Freshness signals to include
```

## Content Creation Prompts

### Prompt 7: Write a Full SEO Article

```
Write a comprehensive SEO article:

Title: "[your title]"
Primary keyword: "[keyword]" — use naturally, ~1% density
Secondary keywords: [list]
Target word count: [1,500–2,500] words
Audience: [beginner / intermediate / expert] [profession or niche]

Structure:
- Compelling intro with hook, keyword in first 100 words
- H2 sections covering: [list your required sections]
- Practical examples and tips throughout
- FAQ section (5 questions)
- Conclusion with CTA to related content

Style: Conversational but authoritative. No padding. Every paragraph adds value.
```

---

### Prompt 8: FAQ Section for Schema

```
Generate an FAQ section for an article about "[topic]":

Requirements:
- 8 questions targeting People Also Ask style queries
- Each answer: 40–60 words (FAQ schema optimized)
- Include the primary keyword "[keyword]" in at least 2 questions
- Cover: definition, how-to, comparison, troubleshooting, best practice
- Format ready for FAQ schema markup (Q/A pairs)
```

## Technical SEO Prompts

### Prompt 9: Technical SEO Audit Checklist

```
Act as a senior technical SEO specialist. I'll describe my site and you'll give me a prioritized audit:

CMS: [WordPress / Astro / Next.js / etc.]
Hosting: [where hosted]
Site size: [approximate pages]
Known issues: [list any you're aware of]
Traffic trend: [growing / flat / declining]

Provide a prioritized checklist covering:
1. Core Web Vitals optimization
2. Crawlability and indexation
3. Site architecture
4. Schema markup gaps
5. Mobile optimization
6. Page speed improvements
7. Internal link structure

Prioritize by impact: high / medium / low.
```

### Prompt 10: Schema Markup Generator

```
Generate JSON-LD schema markup for:
Content type: [Article / FAQ / HowTo / Product / LocalBusiness]
Title: "[title]"
URL: [url]
Published: [date]
Author: [name or organization]
Description: [description]

For FAQ schema, include these Q&As:
Q: [question 1] — A: [answer 1]
Q: [question 2] — A: [answer 2]

Output valid JSON-LD ready to paste into the <head> section.
```

## Frequently Asked Questions

### Can ChatGPT replace SEO tools like Ahrefs or SEMrush?

No. ChatGPT doesn't have access to live search data or backlink databases. Use it alongside your SEO tools — ChatGPT for strategy, writing, and content ideation; specialist tools for data and tracking.

### How accurate is ChatGPT for SEO advice?

ChatGPT has strong knowledge of SEO fundamentals through its training cutoff, but may not reflect the latest algorithm updates. Always cross-check recommendations against current Google documentation and trusted SEO sources.

### Will Google penalize AI-written content?

Google targets low-quality, spammy content — not AI content by default. If you use ChatGPT to produce genuinely helpful, accurate, well-researched content and add your own expertise and editing, it ranks like any other quality content.

### What's the single most valuable SEO prompt here?

Prompt 5 (the full content brief) consistently generates the highest ROI. A great content brief before writing saves more time and produces better results than any optimization after the fact.

### How do I use these prompts for local SEO?

Include your city, business type, and local keywords in every prompt. Ask specifically for Google Business Profile optimization tips, local citation strategies, and locally-relevant content topics.
