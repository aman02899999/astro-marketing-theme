Learning and development professionals who use AI produce more training material in less time — without sacrificing instructional quality. These prompts cover every phase of the L&D workflow from needs analysis through evaluation.

## Needs Analysis Prompts

### Prompt 1: Training Needs Analysis Framework

```
Help me conduct a training needs analysis for:

Organization: [type and size]
Performance gap: [what employees can't do that they need to be able to do]
Affected population: [who needs training — role, department, size]
Business impact: [what happens if this gap isn't closed?]
Data I have: [performance reviews / survey results / manager feedback / incident reports]

Framework:
1. Root cause analysis: Is this a knowledge gap, skill gap, motivation gap, or system/process issue?
   (If it's not a knowledge/skill gap, training won't fix it — flag this)
2. Priority matrix: impact × frequency of the behavior gap
3. Learning objectives for each gap area
4. Recommended training modality for each gap (classroom / eLearning / on-the-job / coaching)
5. Prerequisites (what learners need to know BEFORE this training)
6. Success metrics (how will we know training worked?)
7. Estimated time/resources needed
```

### Prompt 2: Learning Objectives Writer

```
Write learning objectives for a training program on: [topic]

Audience: [learner role and experience level]
Performance context: [where they'll use this skill — on the job context]
Content coverage: [topics to cover]
Duration: [training length]

For each topic, write objectives using Bloom's Taxonomy:
- Knowledge level: "Learners will be able to [recall/identify/define]..."
- Comprehension level: "Learners will be able to [explain/describe/distinguish]..."
- Application level: "Learners will be able to [apply/use/demonstrate]..."
- Analysis level: "Learners will be able to [analyze/compare/examine]..."
- Synthesis/Evaluation level (if appropriate): "Learners will be able to [design/evaluate/create]..."

Each objective: specific, measurable, achievable, relevant, time-bound (SMART).
For a [X]-hour training, suggest 3–5 total objectives.
```

## Content Development Prompts

### Prompt 3: eLearning Script Writer

```
Write an eLearning module script for:

Module title: [title]
Learning objective: [what learners will be able to DO]
Duration: [X minutes]
Audience: [role and knowledge level]
Tone: [professional / conversational / scenario-based]

Module structure:
1. Introduction (60 seconds): why this matters — WIIFM (what's in it for me)
2. Content blocks (3–4, each 2–3 minutes):
   For each: concept introduction → example → application activity
3. Knowledge check (2–3 questions after key concepts)
4. Scenario or case study (authentic, relatable situation)
5. Summary (key takeaways — repeat the learning objective)
6. Final assessment question

Format: narrator script + [SLIDE: description] + [INTERACTION: type] markers.
Avoid: talking-head monologue for more than 90 seconds. Build in interactions.
```

### Prompt 4: Scenario-Based Learning Design

```
Design a scenario-based learning exercise for:

Skill to develop: [complex skill — e.g. "handling difficult customer conversations" / "applying the performance review framework"]
Audience: [learner profile]
Realistic context: [the actual work situation where this skill is needed]
Common mistakes learners make: [what typically goes wrong]

Scenario structure:
1. Setup: realistic context, character introduction, stakes (why does this decision matter?)
2. Decision point 1: learner chooses from 3 options
   - Option A: best practice response
   - Option B: common mistake
   - Option C: plausible but not optimal
3. Consequence + feedback for each option (show realistic outcomes)
4. Decision point 2: follows from the scenario progression
5. Resolution: what the best path looks like end-to-end
6. Debrief questions: 3 reflection questions

Feedback for wrong answers: explain WHY without sounding preachy.
```

## Assessment Prompts

### Prompt 5: Post-Training Assessment

```
Create a post-training assessment for:

Training topic: [topic]
Learning objectives covered: [paste objectives]
Audience: [role]
Assessment purpose: [knowledge check / certification / performance gate]
Time limit: [X minutes]
Pass/fail threshold: [X% to pass]

Include:
- [X] multiple choice (application level — not recall)
- [X] scenario questions (judge what action to take)
- [X] short answer (explain or justify)

For multiple choice: 4 options, one clearly correct, distractors based on common misconceptions.
For scenario questions: realistic situation + "what should you do?" + 3 plausible options.

After assessment: answer key + rationale for each correct answer + reference to relevant training content.
```

### Prompt 6: Kirkpatrick Level 3 Evaluation Plan

```
Design a Level 3 (Behavior) evaluation plan for:

Training: [name and brief description]
Skill trained: [what the training taught]
Time since training: [evaluation happens X weeks/months post-training]
Business process where behavior should appear: [where to look for behavior change]

Level 3 evaluation plan:
1. Behavioral indicators (observable evidence that learning transferred)
2. Data collection methods (observation checklist / manager survey / performance data / 360 feedback)
3. Timing (when to measure — immediate / 30 days / 90 days)
4. Baseline (what did behavior look like BEFORE training?)
5. Manager enablement (what managers need to do to support transfer)
6. Survey questions for learners (self-assessment of behavior change)
7. Survey questions for managers (observed behavior change)
8. Success threshold (what % behavior change = training success)
```

## Frequently Asked Questions

### What L&D tasks benefit most from ChatGPT?

Writing learning objectives (Prompt 2), scripting eLearning modules (Prompt 3), and creating assessment questions (Prompt 5) are the highest-ROI applications. These tasks are time-consuming, require consistency, and follow learnable patterns that ChatGPT executes well. Instructional design judgment — knowing what to teach and how to sequence it — still requires human expertise.

### Can ChatGPT replace instructional designers?

No. Instructional design requires deep understanding of adult learning theory, organizational context, subject matter expertise, and the judgment to know when training is the wrong intervention (Prompt 1 addresses this). ChatGPT is an extremely efficient content production tool in the hands of an experienced L&D professional — it doesn't replace the professional.

### How do I ensure eLearning scripts don't sound like AI?

Give ChatGPT your own voice examples. Paste 1–2 paragraphs you've written in your training scripts and say "Match this tone and voice." Also explicitly prohibit AI-typical phrases: "It's important to note that," "Certainly," "In this module, you will learn." The more specific your style guidance, the more natural the output.

### What's the difference between Level 1 and Level 3 evaluation?

Level 1 (Reaction): did learners like the training? (smile sheets). Level 2 (Learning): did learners acquire the knowledge or skill? (assessment scores). Level 3 (Behavior): did learners apply the learning on the job? (observation, manager surveys). Level 4 (Results): did it impact business outcomes? Most organizations measure Level 1 and 2 only — Prompt 6 helps you design the more valuable Level 3 evaluation.

### How do I design training for remote/distributed teams?

Replace synchronous elements with asynchronous where possible (recorded video + discussion forums instead of live sessions). Build in more frequent, shorter interactions instead of long modules. Add peer learning components (cohort discussions, pair exercises). Use ChatGPT to generate discussion prompts, asynchronous activity designs, and self-paced guides that work without a facilitator present.
