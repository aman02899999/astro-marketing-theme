E-commerce SEO lives or dies on product pages, category pages, and your ability to handle duplicate content at scale. These prompts help you write optimized content for every product, build category pages that rank, and handle the unique technical challenges of online stores.

## Product Page Prompts

### Prompt 1: Product Description Generator

```
Write an SEO-optimized product description for:

Product name: [name]
Product type: [category]
Key features: [list 5–7]
Benefits (not features): [what each feature does FOR the customer]
Target customer: [who buys this]
Target keyword: "[primary keyword]"
Price point: [$X — helps set the tone: budget / mid-range / premium]
Brand voice: [technical / accessible / luxury / playful]

Description format:
- Opening paragraph: lead with the most compelling benefit + keyword (100 words)
- Features and benefits: formatted for easy scanning
- Use case section: who this is for and specific scenarios
- Technical specs (below the fold): [list specs if applicable]

SEO requirements:
- H1: the product name (already exists — just include keyword naturally)
- Meta description: 155 characters (include keyword + benefit + soft CTA)
- First 100 words: include primary keyword once naturally
- Total: 250–400 words for the main description
```

### Prompt 2: Product Description at Scale

```
I need to write product descriptions for [X] similar products in the [category] category.

Sample products:
1. [Product name] — key differentiator: [what makes it unique]
2. [Product name] — key differentiator: [what makes it unique]
3. [Product name] — key differentiator: [what makes it unique]

Brand voice: [description]
Shared keyword theme: "[category keyword]"

Create a reusable template structure for this category, then write the description for each product using that template.

Requirements:
- Each description must be unique (no duplicate content)
- Each must lead with its specific differentiator
- Keep the same structure and word count across all products
- Vary sentence openings so they don't all sound identical
```

## Category Page Prompts

### Prompt 3: Category Page SEO Content

```
Write SEO-optimized category page content for:

Category: [category name]
Primary keyword: "[keyword]"
Product types in this category: [list]
Target customer: [who shops this category]
Store type: [Shopify / WooCommerce / Magento / custom]

Content to include:
1. H1: category name (include keyword)
2. Introduction paragraph (150 words — before the product grid):
   - What this category covers
   - Why buy from us (brief — value prop)
   - Include keyword naturally
3. Below-the-grid content (250 words):
   - Buying guide: how to choose the right [product type]
   - Key decision factors (3–4 bullets)
   - Brief FAQ (3 questions specific to this category)

Meta title: [category name] — [store name] | [benefit phrase] (under 60 chars)
Meta description: 155 characters including keyword + value proposition
```

---

### Prompt 4: E-Commerce FAQ Content

```
Write FAQ content for a [product type] product page:

Product: [name and description]
Common pre-purchase questions: [list 5–8 real questions customers ask before buying]
Common post-purchase questions: [list 3–5 questions about use/care/returns]
Target keywords for FAQ: [list related question-based keywords]

For each question:
- Rephrase as customers naturally ask it (People Also Ask style)
- Answer in 40–60 words (FAQ schema optimized)
- Include the keyword naturally where it fits
- Link to: [return policy / size guide / shipping page] where relevant

Format as FAQ schema-ready JSON-LD at the end.
```

## Technical E-Commerce SEO Prompts

### Prompt 5: Duplicate Content Strategy

```
Help me create a duplicate content strategy for my e-commerce site:

Platform: [Shopify / WooCommerce / Magento / custom]
Types of potential duplicate content:
- [product variants with identical descriptions — e.g. same product in different colors]
- [product appearing in multiple categories]
- [paginated category pages (/page/2, /page/3)]
- [filtered/sorted versions of category pages (?sort=price)]
- [printer-friendly versions]
- [www vs non-www]

For each duplicate content type:
1. What causes it
2. Recommended solution (canonical / noindex / parameter handling / unique content)
3. Implementation for [my platform]
4. Priority (critical / important / nice-to-have)

Also: canonical tag rules I can give to my developer.
```

## Frequently Asked Questions

### How important is product description uniqueness for SEO?

Extremely important. Manufacturer descriptions used by multiple retailers are a common source of duplicate content penalties. Even if individual pages aren't penalized, they won't rank when competing with the manufacturer's own page or established retailers. Unique, benefit-focused descriptions using ChatGPT (Prompt 1) give you a real ranking advantage.

### Should category pages have long content?

Yes — but structured correctly. Product grid first (users want to browse), then SEO content below the grid, then FAQ at the bottom. Google needs content to understand what the page is about; users don't want a wall of text before they can see the products. Prompt 3 gives you the right structure.

### How do I handle product variants (color, size) without duplicate content?

Use canonical tags pointing all variant URLs to the main product URL. The main product page should mention all variants, but the core SEO content shouldn't duplicate across variant pages. Prompt 5 addresses this directly for different platforms.

### What's the best Shopify SEO improvement I can make today?

Fix your collection (category) page descriptions — most Shopify stores have blank or thin category pages. Category pages can rank for high-volume head terms that individual product pages can't. Use Prompt 3 to write optimized content for your top 10 collection pages and you'll typically see results within 3 months.

### Should product pages target long-tail or head keywords?

Both — but strategically. Head keywords (e.g. "running shoes") belong on category pages. Long-tail keywords (e.g. "lightweight trail running shoes for wide feet") belong on product pages. This structure mirrors how Google assigns relevance and prevents your product and category pages from competing against each other.
