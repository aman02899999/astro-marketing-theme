YouTube is a search engine. Your titles, descriptions, and scripts all affect whether your videos get found, watched, and shared. These ChatGPT prompts help you create better videos faster — and grow a channel that actually gets traction.

## Script Writing Prompts

### Prompt 1: Full YouTube Video Script

```
Write a complete YouTube video script for:

Video title: "[your title]"
Target audience: [who watches your channel]
Video length: [8–12 minutes / 15–20 minutes / etc.]
My style: [casual / educational / storytelling / documentary / talking head]
Key point the viewer takes away: [one sentence]

Script sections:
1. HOOK (first 30 seconds — must grab attention before the skip)
2. INTRO (channel intro + what this video covers + why it matters)
3. MAIN CONTENT (H2 sections with timestamps marked as [00:XX])
4. TRANSITIONS (natural connectors between sections)
5. OUTRO (subscribe CTA + next video recommendation + comment prompt)

Format: Include [B-ROLL SUGGESTION] notes and [ON-SCREEN TEXT] cues throughout.
```

### Prompt 2: Hook Generator

```
Write 10 different hooks for a YouTube video about "[topic]".

Hook types to include:
1. Bold claim ("Most [audience] are doing [X] completely wrong...")
2. Story opening ("Three months ago I [situation]...")
3. Question hook ("What if [surprising idea]?")
4. Contrast hook ("Everyone says [common advice]. Here's why that's backward.")
5. Curiosity hook ("By the end of this video, you'll know [intriguing outcome]")
6. Statistics hook ("According to [source], [surprising stat]...")
7. Failure/lesson hook ("I [failed at X] so you don't have to...")
8. Controversy hook ("I'm going to say something that most [niche] creators won't...")
9. Pattern interrupt hook (Unusual opening line that creates confusion then resolves)
10. Social proof hook ("After helping [X] people with [topic]...")

Rank the top 3 for a [describe your audience] and explain why.
```

### Prompt 3: Educational Video Script Outline

```
Create a structured outline for an educational YouTube video:

Topic: "[topic]"
Target viewer: [experience level and profile]
Video goal: [what viewer can DO after watching]
Length: [X minutes]

Outline format:
- Hook (with specific approach)
- Problem statement (why this matters to viewer)
- Main sections (each with: key point, example, visual suggestion)
- Common mistakes section (optional but high-engagement)
- Summary and CTA

Include:
- Timestamp plan
- Pattern interrupt moments (to re-engage viewers)
- 3 engagement questions to ask on camera
```

## Title and Thumbnail Prompts

### Prompt 4: YouTube Title Generator

```
Write 20 YouTube title variations for a video about "[your topic]".

Target keyword: "[primary keyword]"
Target audience: [who watches]
Video angle: [your specific take on the topic]

Generate titles in these styles (4 each):
1. List/number format ("X Ways to...")
2. How-to format
3. Question format
4. "Secret/Unknown/Mistake" format
5. Results-driven format ("How I [achieved X] in [timeframe]")

For each title: estimate click-through appeal (1–10) and explain.
Flag the top 3 you'd actually test first.
```

### Prompt 5: Thumbnail Concept Generator

```
Generate 5 thumbnail concepts for a YouTube video titled: "[your title]"

For each concept describe:
1. Background: [color / scene / image type]
2. Focal element: [main visual — face expression / graphic / object]
3. Text overlay: [3–5 words maximum, font weight]
4. Color scheme: [specific colors and their roles]
5. Emotion the thumbnail should trigger: [curiosity / shock / excitement / etc.]
6. Why it would stop the scroll

Thumbnail size context: must read clearly at 168×94px (search results size).
```

## YouTube SEO Prompts

### Prompt 6: SEO-Optimized Video Description

```
Write a YouTube video description for:

Video title: "[title]"
Target keywords: [primary + 3 secondary]
Video content summary: [what the video covers]
Channel name: [name]
Links to include: [placeholders for your links]

Description structure:
- First 2 sentences (above the fold): hook + keyword-rich summary
- Detailed description (200 words): what viewers learn, key points covered
- Chapters section: [CHAPTERS with timestamps — leave as template]
- Links section: [playlist / related videos / website / social]
- Hashtags: (3–5 relevant ones)
- Call to subscribe

Optimize for: YouTube search for "[primary keyword]"
```

## YouTube Shorts Prompts

### Prompt 8: Shorts Script Generator

```
Write 5 YouTube Shorts scripts on the topic of: "[topic]"

Each Short:
- Duration: 45–60 seconds (approximately 130–150 words spoken)
- Hook: First 2 seconds must be scroll-stopping
- Format: [tip / story / reaction / tutorial / list]
- Pacing: Fast — one new idea or sentence every 3–4 seconds

For each script include:
- On-screen text overlay cues [ON-SCREEN: ...]
- Visual cut suggestions [CUT TO: ...]
- Spoken script
- Final CTA (subscribe / comment / watch next)
```

## Frequently Asked Questions

### How long should a YouTube video script be?

For a 10-minute video, aim for 1,400–1,600 words of spoken script (average speaking pace is ~140 words per minute). Add time for B-roll and on-screen text. ChatGPT's scripts tend to run long — always read them aloud to check timing before filming.

### Do YouTube titles really affect views that much?

Massively. Your title and thumbnail are the only tools you have to get someone to click. A great video with a weak title might get 2% CTR. The same video with a better title could get 8–12%. Prompt 4 gives you 20 options to A/B test — use YouTube Analytics to find what works for your audience.

### How many hashtags should I use in YouTube descriptions?

Three to five, placed at the bottom of the description. YouTube ignores hashtag stuffing. Use your niche keyword, a broader category keyword, and your brand name. Don't use trending hashtags unless they're genuinely relevant — it doesn't help.

### What's the best video length for YouTube growth?

For new channels: 8–15 minutes. Long enough to build watch time, short enough to not lose viewers. For established channels: whatever length your audience responds to — check your Average View Duration in Analytics. If viewers drop off after 5 minutes, your videos are probably too long.

### Can ChatGPT write scripts that match my voice?

Yes, with examples. Give it 2–3 samples of your existing scripts or transcripts and say "Match this style and tone." The more examples you provide, the better the style match. Always read the script aloud and edit any lines that don't sound like you.
