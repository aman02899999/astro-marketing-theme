Teachers who use AI don't teach better because of AI — they teach better because AI gives them their time back. These prompts eliminate the most time-consuming administrative tasks in teaching so you can spend more time on the work that actually matters: your students.

## Lesson Planning Prompts

### Prompt 1: Full Lesson Plan Generator

```
Create a complete lesson plan:

Subject: [subject]
Grade level: [grade or age range]
Topic: [specific lesson topic]
Duration: [X minutes]
Learning standards: [paste your standards or "use common core for [grade/subject]"]
Prior knowledge: [what students already know]
Learning objectives: [what students will be able to do after this lesson]

Include:
1. Objectives (SMART format, using Bloom's Taxonomy verbs)
2. Materials and resources needed
3. Warm-up / hook activity (5 minutes)
4. Direct instruction section with key teaching points
5. Guided practice activity
6. Independent practice
7. Closure activity
8. Formative assessment method
9. Differentiation: [for advanced / for struggling learners / for ELL students]
10. Homework (optional)

Format as a ready-to-use teacher-facing document.
```

### Prompt 2: Unit Plan Framework

```
Create a unit plan framework for:

Subject: [subject]
Grade: [grade level]
Unit title: [title]
Duration: [X weeks]
Essential questions: [big ideas students explore — or ask ChatGPT to generate]
Standards covered: [list or "generate aligned to [curriculum]"]
Culminating project or assessment: [final product]

Output:
1. Unit overview (2 paragraphs)
2. Week-by-week lesson sequence (topics only)
3. Key vocabulary list
4. Suggested texts, resources, and materials
5. Assessment plan (formative throughout + summative)
6. Cross-curricular connections
```

### Prompt 3: Differentiated Instruction Planner

```
I'm teaching [topic] to [grade level] students with diverse needs:

Grade-level learners: [X students]
Advanced learners: [X students — describe their level]
Struggling learners: [X students — describe their challenges]
ELL students: [X students — language proficiency level]
Students with IEP accommodations: [brief description of needs]

Create a differentiated version of this activity: [describe the core activity]

For each group provide:
- Modified task description
- Scaffolds or supports provided
- Extension or challenge modifications
- Materials modifications
- Assessment flexibility
```

## Assessment Prompts

### Prompt 4: Quiz and Test Generator

```
Create a [quiz / test / exit ticket] for:

Subject: [subject]
Topic: [specific topic]
Grade level: [grade]
Duration: [X minutes]
Difficulty: [grade-level / challenging / mixed]

Include:
- [X] multiple choice questions (4 options each, one clearly correct)
- [X] short answer questions
- [X] true/false questions (with "explain your answer" prompt)
- [X] one extended response question

After the test, provide:
- Answer key with brief explanations
- Point value suggestions
- Notes on which questions target which learning objective
```

### Prompt 5: Rubric Creator

```
Create a grading rubric for:

Assignment type: [essay / project / presentation / lab report / creative work]
Subject: [subject]
Grade level: [grade]
Total points: [X points]
Assignment description: [brief description]

Rubric format: 4-level scale (4=Exceeds / 3=Meets / 2=Approaching / 1=Beginning)

Categories to assess (suggest if unsure):
- [Category 1]
- [Category 2]
- [Category 3]
- [Category 4]

For each category and level: specific, observable, measurable descriptors.
Include a "Notes" column for teacher comments.
```

## Student Feedback Prompts

### Prompt 6: Written Feedback Generator

```
Write constructive written feedback for a student assignment:

Assignment: [what the student submitted — describe it]
Student work summary: [paste or describe what the student did]
Strengths: [what they did well]
Areas for growth: [what needs improvement]
Grade level: [grade]
Feedback tone: [encouraging / direct / balanced]

Feedback structure:
1. Opening: acknowledge effort and one specific strength
2. Middle: 2 specific areas for improvement with concrete suggestions
3. Next step: one actionable thing they should do next
4. Close: encouraging forward-looking statement

Keep under 150 words. No generic praise ("Good job!"). Be specific.
```

### Prompt 7: Parent Communication Templates

```
Write parent communication templates for:

Grade level: [grade]
Subject: [your subject]
School context: [public / private / type of school]

Create templates for:
1. Introduction letter (start of year)
2. Positive achievement note (student doing well)
3. Academic concern letter (student struggling)
4. Behavioral concern email (sensitive but clear)
5. Invitation to parent-teacher conference
6. Newsletter section update

Each template:
- Professional but warm tone
- Adaptable to any student (use [Student Name])
- Under 200 words
- Include subject line for emails
```

## Frequently Asked Questions

### Is it ethical to use ChatGPT for lesson planning?

Yes — just as using a curriculum guide or textbook teacher's edition is ethical. ChatGPT is a tool for reducing administrative burden. Your professional judgment, classroom context, and relationship with your students can't be automated. Use AI to handle the scaffolding so you can focus on the human elements of teaching.

### How do I prevent students from using ChatGPT to cheat?

Design assessments that require personal reflection, local context, or in-class demonstration. Portfolio-based assessment, oral explanation of written work, process documentation, and in-class writing make AI assistance much harder to misuse. Prompts 4 and 5 help you create assessments with these qualities.

### What's the most time-saving use of ChatGPT for teachers?

Feedback generation (Prompt 6). Writing individualized feedback on 30 papers in an afternoon is one of teaching's most time-consuming tasks. ChatGPT can draft feedback in seconds that you then personalize and refine. Many teachers report saving 5–8 hours per week on feedback alone.

### Can ChatGPT create standards-aligned content?

Yes, with specificity. Include the exact standard code (e.g., CCSS.ELA-LITERACY.W.5.1) in your prompt. ChatGPT has knowledge of Common Core, NGSS, and many state standards. Always verify alignment yourself — ChatGPT can misattribute standards, especially for recent updates.

### How do I handle the digital divide when using AI-assisted teaching materials?

Design for the lowest common technology denominator in your classroom. AI tools help you create better print materials just as easily as digital ones. Use AI to create differentiated worksheets, printed rubrics, and paper-based assessments that work for every student regardless of device access.
