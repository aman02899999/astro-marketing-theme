Customer service teams using AI handle more tickets in less time, maintain consistent tone across every agent, and turn complaints into loyalty moments. These prompts cover every scenario from routine support to escalation management.

## Response Template Prompts

### Prompt 1: Complaint Response Generator

```
Write a customer complaint response:

Customer complaint: [paste the complaint verbatim]
What actually happened: [the real situation from your perspective]
Resolution available: [refund / replacement / credit / apology only / investigation]
Brand tone: [empathetic / professional / casual / formal]
Agent name: [name or leave blank]

Response must:
- Open by acknowledging the specific complaint (not generic "we're sorry")
- Take responsibility where appropriate without admitting legal liability
- State the concrete resolution clearly
- Give a timeline if relevant
- Close with a genuine human touch
- Avoid: "We apologize for any inconvenience", "per my last email", corporate speak

Max 150 words.
```

### Prompt 2: Support Template Library

```
Create a support email template library for a [type of business]:

Build templates for these 10 scenarios:
1. Order confirmation
2. Shipping delay notification
3. Item out of stock
4. Refund confirmation
5. Refund request denied (with reason)
6. Account suspended (policy violation)
7. Password reset request
8. Bug report acknowledged
9. Feature request received
10. Subscription cancellation confirmation

Each template:
- Subject line
- Body (under 120 words)
- Placeholders in [brackets] for personalization
- Tone: [your brand tone]
- One genuine human touch per template (not boilerplate)
```

### Prompt 3: Escalation De-escalation Script

```
Write a de-escalation script for an angry customer:

Situation: [describe what happened and why they're upset]
Customer's main frustration: [their core complaint]
What you can offer: [resolution options available]
What you cannot offer: [hard limits]

Script includes:
1. Opening: validate their frustration (don't dismiss, don't over-apologize)
2. Active listening language (2–3 phrases that show you understand)
3. Ownership statement (take responsibility at the right level)
4. Resolution path (clear next steps)
5. Empowerment close (leave them feeling heard and respected)

Also write: what NOT to say in this situation (5 phrases to avoid).
```

## Process and Policy Prompts

### Prompt 4: FAQ Page Builder

```
Build a customer FAQ page for:

Business: [type of business]
Top customer questions I get: [list 10–15 real questions from your support queue]

For each question:
- Rephrase as customers actually ask it (not how you'd phrase it internally)
- Answer in plain language (no jargon)
- Keep each answer under 75 words
- Add a "Still need help?" CTA after every 3–4 questions

Organize into sections:
- Ordering and Payment
- Shipping and Delivery
- Returns and Refunds
- Account and Profile
- Product Questions

Include a search-friendly meta description for the FAQ page.
```

---

### Prompt 5: Chatbot Response Tree

```
Design a customer service chatbot response tree for:

Business type: [description]
Top 5 support request types: [list them]

For each request type create:
1. Trigger phrases (what customers type to activate this flow)
2. Clarifying question (to narrow the issue)
3. Resolution path A (most common scenario)
4. Resolution path B (secondary scenario)
5. Escalation trigger (when to hand off to a human)
6. Human handoff message (warm, not abrupt)

Format as a decision tree with clear branching logic.
```

## Quality and Training Prompts

### Prompt 6: Agent Response Audit

```
Audit this customer service response for quality:

Original customer message: [paste]
Agent's response: [paste]

Evaluate on:
1. Tone (empathetic / appropriate for situation)
2. Accuracy (is the information correct and complete?)
3. Clarity (is it easy to understand?)
4. Resolution (does it actually solve the problem?)
5. Brand voice consistency
6. Length (too long / too short / appropriate)
7. What's missing

Give a score out of 10 and rewrite the response to show what excellent looks like.
```

## Frequently Asked Questions

### How do I maintain a consistent brand voice across all agents?

Create a brand voice reference card (use Prompt 2 as a starting point) and paste it at the top of every ChatGPT session. Define: 3 personality traits, 5 phrases to use, 5 phrases to never use, and an example exchange. Any agent copying templates will automatically match the brand voice.

### Can ChatGPT handle emotionally charged support tickets?

Yes, as a drafting tool — but always have a human review before sending responses to genuinely distressed customers. ChatGPT is excellent at generating empathetic language frameworks (Prompt 3), but the judgment call on how much to escalate, apologize, or compensate requires human context.

### What's the ROI of AI in customer service?

Studies consistently show 30–50% reduction in handle time and 20–40% reduction in ticket volume when AI handles first-response drafting, FAQ deflection, and template-based support. The highest ROI comes from reducing escalations — Prompt 3 addresses this directly.

### Should every customer get an AI-drafted response?

Use AI for drafting, humans for sending. AI drafts should always be reviewed, personalized, and approved before sending — especially for complaints, billing issues, and anything emotionally sensitive. Fully automated responses are only appropriate for transactional confirmations where the content is completely predictable.

### How do I prevent ChatGPT from making up policy information?

Include your actual policy in the prompt. Say: "Our return policy is: [paste policy]. Write a response that accurately reflects this policy and nothing more." Never ask ChatGPT to generate policy responses without providing the actual policy — it will invent plausible-sounding but incorrect details.
