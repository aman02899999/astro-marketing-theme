Great video starts with great preparation. A well-written brief, clear shot list, and structured edit sequence save hours in post-production. These prompts handle the written work that frames successful video projects.

## Pre-Production Prompts

### Prompt 1: Video Production Brief

```
Write a video production brief for:

Video type: [YouTube / ad / corporate / social / product demo / testimonial]
Client/brand: [description]
Goal: [what the video must achieve]
Target audience: [who watches]
Platforms: [where it will be distributed]
Duration: [X seconds / minutes]
Budget range: [low / medium / high — or $X]
Deadline: [date]

Brief sections:
1. Project overview (objective in 2 sentences)
2. Creative concept (the big idea or approach)
3. Key messages (3 things the viewer must take away)
4. Tone and style (mood board description)
5. Must-haves (non-negotiable elements)
6. Must-avoids (things to never do for this brand)
7. Reference videos (describe 2–3 for direction)
8. Deliverables (formats, lengths, cutdowns needed)
9. Approval process and contacts
```

### Prompt 2: Shot List Generator

```
Generate a shot list for:

Video type: [talking head / narrative / product demo / brand / explainer]
Script or description: [paste script or summarize scene by scene]
Location(s): [describe settings]
On-screen talent: [number and type of people]
Products or props: [list]
Style reference: [describe aesthetic]

Shot list format for each scene:
- Scene number
- Shot type (wide / medium / close-up / extreme close-up / cutaway / b-roll)
- Description of what's in frame
- Camera movement (static / pan / tilt / tracking / handheld)
- Audio note (on-camera audio / voiceover / music only)
- Estimated duration

Group by location to minimize setup changes.
Flag: shots that can be captured in one setup (efficiency notes).
```

### Prompt 3: Voiceover Script

```
Write a voiceover script for:

Video type: [explainer / product demo / brand / documentary / ad]
Duration: [X seconds / minutes]
Visual description: [describe what's on screen]
Key messages: [what the VO must communicate]
Tone: [conversational / authoritative / inspiring / warm / urgent]
Brand voice: [adjectives]
CTA: [what to say at the end]

Script rules:
- Written for the ear, not the eye (short sentences, contractions, conversational)
- One idea per sentence
- Timed at ~130 words per minute for normal pace
- [PAUSE] markers for visual impact moments
- Avoid: passive voice, abstract language, corporate jargon

Provide: word count and estimated read time at 3 pace options (slow/normal/fast).
```

## Frequently Asked Questions

### What's the most common pre-production mistake?

Starting production without a locked script or brief. Script changes during a shoot waste expensive time and talent. Brief changes after production begins require reshoots. The prompts in this guide are designed to resolve ambiguity before a single camera rolls.

### How detailed should a shot list be?

Detailed enough that any competent camera operator could shoot the video without you present. Each shot should be clear, and the list should be organized logically (by location and setup) to minimize equipment moves. Prompt 2 structures this efficiency automatically.

### How do I write voiceover that sounds natural when read aloud?

Write the way people actually talk — with contractions, short sentences, and occasional sentence fragments. Then read every line aloud. If you stumble, rewrite. ChatGPT-generated voiceover scripts often need one pass of naturalizing: soften formal constructions, add rhythm variation, and remove any line that feels like a press release.

### What frame rate should I shoot in?

24fps for cinematic/storytelling content. 30fps for corporate and social content. 60fps or 120fps for sports, product demos with movement, or footage you'll slow down in post. When in doubt, shoot at 24fps — it's the most forgiving aesthetic choice.

### How many shots should I plan per minute of final video?

Plan 3–5x more shots than you need in the final edit. A 2-minute video typically needs 30–50 distinct shots in the edit (including b-roll, cutaways, and alternates). Shoot everything on the shot list plus coverage — footage you don't use is never a waste; footage you wish you'd shot always is.
