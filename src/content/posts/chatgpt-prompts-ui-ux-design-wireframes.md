UI/UX designers use ChatGPT to move faster through the parts of the process that aren't about visual craft: user research synthesis, UX copy, persona development, information architecture, and usability analysis. These prompts cover all of it.

## User Research Prompts

### Prompt 1: User Persona Generator

```
Create a detailed user persona for:

Product: [product name and description]
Target user segment: [describe the user group]
Research basis: [interviews with X users / survey data / assumption-based — be honest]

Persona structure:
- Name and photo description (archetypal, not stereotypical)
- Demographics (age range, role, company size if B2B)
- Goals: primary (why they use your product) + secondary
- Frustrations: top 3 pain points related to your product space
- Behavior patterns: how they currently solve the problem
- Tech comfort level: [beginner / intermediate / power user]
- Quote: one sentence that captures their mindset
- A day in their life: 3–4 sentences
- What success looks like for them

Create 2 distinct personas for different user segments.
```

### Prompt 2: User Interview Question Guide

```
Create a user interview guide for:

Research goal: [what you're trying to learn]
Product stage: [pre-launch discovery / existing product improvement / specific feature]
Participant profile: [who you're interviewing]
Interview duration: [45 minutes]

Structure:
1. Warm-up questions (5 minutes, rapport building)
2. Context questions (10 minutes, understand their world)
3. Core research questions (20 minutes, the main focus)
4. Solution exploration (5 minutes, if appropriate)
5. Closing (5 minutes)

For each section:
- 3–4 questions
- Follow-up probes for each
- Things to listen for
- Things to avoid asking (leading questions)

Include a pre-interview brief and consent note.
```

---

### Prompt 3: Usability Test Script

```
Write a usability test script for:

Product: [name and description]
Test type: [moderated in-person / remote / unmoderated]
Tasks to test: [list 3–5 specific tasks or user flows]
Participant profile: [who you're testing with]
Duration: [X minutes]

For each task include:
- Task scenario (realistic context, not instructions)
- What you're observing (completion, errors, confusion points)
- Post-task question
- Metrics to capture (time on task, success rate, errors)

Include: intro script, think-aloud instruction, debrief questions.
```

## UX Copy Prompts

### Prompt 4: Microcopy Generator

```
Write UX microcopy for these interface elements:

Product: [what the product does]
User context: [what the user is trying to accomplish]
Brand voice: [3 adjectives]

Generate copy for:
1. Empty state: [component name — e.g. "projects list when user has none"]
2. Error message: [error scenario — e.g. "form submission failed, server error"]
3. Onboarding tooltip: [feature to explain]
4. Confirmation dialog: [destructive action — e.g. "delete account"]
5. Success notification: [action completed — e.g. "payment processed"]
6. Loading state: [long operation — e.g. "generating report"]

For each: headline, body copy (under 20 words), and CTA label.
```

---

### Prompt 5: Onboarding Flow Copy

```
Write complete onboarding flow copy for:

Product: [name and description]
User goal: [what they're trying to achieve on day 1]
Key actions in onboarding: [list 3–5 setup steps]
Tone: [friendly / minimal / encouraging / professional]

For each onboarding step:
- Screen title (under 5 words)
- Body explanation (under 30 words)
- Primary CTA label
- Optional secondary CTA (skip / learn more)
- Progress indicator text

Also write: welcome modal headline + 2-sentence description.
```

## Information Architecture Prompts

### Prompt 6: Navigation Structure

```
Design a navigation structure for:

Product type: [web app / mobile app / website]
Product: [description and main use cases]
User goals (top 3): [what users primarily want to do]
Content types: [list all sections/features]
User types: [if multiple roles exist]

Output:
1. Primary navigation items (max 7 for web, max 5 for mobile)
2. Secondary navigation per section
3. Rationale for the groupings
4. Items that should be in a utility/settings area
5. Mobile navigation pattern recommendation
6. Search placement recommendation

Apply card-sorting logic: group by user mental model, not company org chart.
```

### Prompt 7: Wireframe Brief

```
Write a wireframe brief for:

Screen name: [screen/page name]
User goal: [what the user is trying to accomplish on this screen]
User arrives from: [previous screen/flow]
User leaves to: [next action/screen]
Primary action: [the one thing this screen must make easy]
Secondary actions: [supporting actions]
Content requirements: [what information must appear]
Constraints: [technical, legal, or design system constraints]

Output:
1. Screen purpose statement (1 sentence)
2. Above-the-fold priority (what appears first)
3. Component list with priority ranking
4. Hierarchy notes for the designer
5. Edge cases to design for (empty state / error / loading / max content)
6. Accessibility considerations
```

## Frequently Asked Questions

### Can ChatGPT replace user research?

No — and you shouldn't try. ChatGPT can help you plan research, write interview guides, synthesize notes, and generate hypothesis personas. But actual user insight comes from real conversations with real users. Use AI to remove the administrative burden around research, not to replace the research itself.

### What's the most valuable use of ChatGPT in UX design?

UX copy and microcopy. Most designers are visual thinkers who find copywriting slow. ChatGPT can generate 10 variations of an error message or empty state in 30 seconds, giving you options to pick from rather than staring at a blank text field in Figma.

### How do I use ChatGPT in a design sprint?

Monday (Define): Summarize research and generate HMW questions. Tuesday (Sketch): Generate multiple solution concepts in text form to sketch from. Wednesday (Decide): Evaluate options against criteria. Thursday (Prototype): Write all copy and content. Friday (Test): Synthesize user feedback from notes into patterns.

### What design tool integrations exist for ChatGPT?

Figma has several AI plugins that call GPT-4 directly. Copy Pilot, Automator, and Builder.io's AI tools are popular. You can also use ChatGPT standalone to generate content and copy-paste into Figma — it's lower friction than it sounds for most workflows.

### How do I keep AI-generated UX copy consistent with brand voice?

Create a "voice and tone" document for ChatGPT to reference. Include: 4–5 personality adjectives, 3 example sentences that capture the voice, 5 phrases to avoid, and 1 direct competitor example of what NOT to sound like. Paste this at the top of every UX copy prompt.
