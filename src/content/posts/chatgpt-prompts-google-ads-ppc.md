Great PPC copy is precise and persuasive in very few characters. These prompts apply copywriting principles specifically to the constraints of Google Ads — where every character counts and relevance determines your Quality Score.

## Google Ads Copy Prompts

### Prompt 1: Responsive Search Ad Copy Generator

```
Write Google Responsive Search Ad copy for:

Product/service: [description]
Target keyword: "[keyword]"
Landing page: [URL or description]
Unique value proposition: [what makes you better]
Target audience: [who searches this keyword]
Geographic focus: [local / national / international]

Responsive Search Ad requirements:
Headlines (15 options, each under 30 characters):
- 5 keyword-focused headlines (include keyword naturally)
- 5 benefit/outcome headlines
- 5 differentiator/trust headlines (price / guarantee / awards / years in business)

Descriptions (4 options, each under 90 characters):
- 2 benefit-focused with CTA
- 1 social proof + CTA
- 1 urgency or offer + CTA

For each headline/description: note the intent it targets (informational / commercial / transactional).
```

---

### Prompt 2: Ad Extension Copy

```
Write ad extension copy for a Google Ads campaign for: [business type]

Target keyword theme: [keywords]
Business highlights: [list your top features, offers, and differentiators]

Write extensions:

SITELINK EXTENSIONS (4–6, each under 25 characters):
- Service-specific pages
- Trust pages (reviews, about, case studies)
- Action pages (get quote, contact, buy now)
For each: headline + 2-line description (35 chars each)

CALLOUT EXTENSIONS (8–10, each under 25 characters):
- Short benefit phrases that don't fit in ad copy
Examples: "Free Shipping," "24/7 Support," "No Contracts"

STRUCTURED SNIPPETS (1 per category):
- Services / Features / Types / Brands

PROMOTION EXTENSION (if applicable):
- Offer type + monetary value + item + promo code + dates
```

## Landing Page Alignment Prompts

### Prompt 3: Ad-to-Landing Page Alignment Checker

```
Check my ad-to-landing page alignment for better Quality Score:

My ad:
Headline 1: [text]
Headline 2: [text]
Description: [text]
Final URL: [URL]

My landing page (describe or paste key sections):
[headline / hero / value prop / CTA]

Audit:
1. Message match (does the landing page deliver on the ad's promise?)
2. Keyword consistency (is the search term reflected in landing page headline?)
3. CTA alignment (does landing page CTA match ad's implied next step?)
4. Load speed considerations (any heavy elements that hurt Quality Score?)
5. Trust signals present (reviews / guarantees / logos)
6. Above-the-fold audit (what visitors see before scrolling)

Recommended improvements to increase Quality Score and conversion rate.
```

## Frequently Asked Questions

### How does ChatGPT improve Google Ads performance?

By generating more headline and description variations than most PPC managers write manually. Responsive Search Ads improve with more high-quality assets — ChatGPT can produce 15 distinct, relevant headlines in minutes versus 30+ minutes of manual writing. More variation = better machine learning optimization by Google's algorithm.

### What character limits should I memorize for Google Ads?

RSA headlines: 30 characters. RSA descriptions: 90 characters. Sitelink headlines: 25 characters. Sitelink descriptions: 35 characters. Callouts: 25 characters. These are strict limits — even one character over means rejection. ChatGPT respects these when they're specified in the prompt.

### How do I write headlines that include keywords without sounding robotic?

Include the keyword naturally as part of a benefit statement. "Best CRM Software" (keyword stuffed) vs. "CRM Software That Closes More Deals" (keyword in benefit context). The second version includes the keyword, serves the reader, and is more compelling. Prompt 1 separates keyword-focused and benefit-focused headlines for this reason.

### What's the most impactful Google Ads copy change?

Improving the headline 1-2 combination, because headlines are what searchers read first. A keyword-relevant H1 + compelling benefit H2 combination outperforms any other single change. Everything else (descriptions, extensions) matters after you've nailed the headline story.

### Should ad copy focus on features or benefits?

Benefits for awareness and consideration; features for high-intent transactional queries. Someone searching "project management software" needs benefits ("Ship faster, stress less"). Someone searching "project management software with Gantt charts" already knows what they want and needs feature confirmation. Match the specificity of your copy to the specificity of the search intent.
