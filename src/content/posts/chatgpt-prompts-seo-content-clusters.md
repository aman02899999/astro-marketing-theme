The sites that dominate Google aren't ranking one article — they're ranking dozens of interlinked articles on the same topic. This is topic authority, and the content cluster model is how you build it. These ChatGPT prompts handle the strategy and production.

## Topic Authority Strategy Prompts

### Prompt 1: Content Cluster Mapper

```
Build a complete content cluster map for the topic: "[main topic]"

My website: [brief description]
My audience: [who reads my site]
Domain authority level: [new site / DA 20–40 / DA 40+]

Create a hub-and-spoke content cluster:

PILLAR PAGE (1):
- Topic: [main keyword]
- Format: comprehensive guide (3,000–5,000 words)
- What it covers: all major subtopics at overview level

CLUSTER PAGES (12–20):
For each cluster page provide:
- Title and target keyword
- Search intent
- How it relates to the pillar
- Estimated search volume tier (high/medium/low)
- Internal links: which other cluster pages it links to and receives links from
- Content format (how-to / list / comparison / definition / case study)

GROUP cluster pages into 3–4 sub-themes.
Show the internal linking map as a text diagram.
```

### Prompt 2: Pillar Page Blueprint

```
Create a detailed blueprint for a pillar page on: "[topic]"

Target audience: [who will read this]
Primary keyword: "[keyword]"
Secondary keywords: [list 5–8]
Competitor pillar pages I need to beat: [describe or list URLs if known]

Blueprint structure:
1. H1 title and URL slug
2. Meta title and description
3. Introduction approach (what hook/angle to take)
4. Complete H2/H3 outline with:
   - Word count per section
   - What the section covers
   - Internal links to add (cluster pages — label as [CLUSTER LINK: topic])
   - External authority links needed (label as [CITE: source type])
5. Featured snippet opportunities (which sections to optimize)
6. Schema markup types to implement
7. Visual elements (tables, diagrams, comparison charts)
8. FAQ section (10 questions)
9. CTA at the end
10. Update cadence recommendation
```

### Prompt 3: Content Gap Analysis

```
Perform a content gap analysis for my site vs competitors:

My site topic: [your main topic]
My existing content: [list your main articles or topic areas]
Competitors to analyze: [describe their content if you know it, or ask ChatGPT to hypothesize based on the niche]

Identify:
1. Topics my competitors likely cover that I don't
2. Keywords I'm probably missing from my cluster
3. Content formats that typically perform in this niche that I haven't created
4. User questions I haven't answered
5. Funnel stages I haven't targeted (awareness / consideration / decision)

Output: Prioritized list of content gaps ranked by traffic potential and business value.
```

## Internal Linking Prompts

### Prompt 4: Internal Linking Audit

```
Build an internal linking strategy for my content cluster on [topic].

My published articles (list titles and their target keywords):
[paste your article list]

For each article, specify:
1. Which 3–5 other articles it should link TO (with suggested anchor text)
2. Which 3–5 articles should link TO it (contextual link opportunities)
3. Whether it's a pillar or cluster page
4. Link priority (high / medium / low based on traffic potential)

Also provide:
- Hub page recommendation (which article should be the pillar)
- Link equity flow diagram (text format)
- Orphan content risks (articles with no inbound links)
```

---

### Prompt 5: Anchor Text Strategy

```
Create an anchor text strategy for internal links to: "[target page title]"

Target page keyword: "[primary keyword]"
Pages that could link to it: [list 5–10 source pages]

For each source page, suggest:
- Exact anchor text to use (vary these — don't repeat exact match)
- Where in the content to place the link (intro / relevant section / conclusion)
- The context sentence that would naturally contain the link

Anchor text variety guidelines:
- 2 exact match anchors
- 3 partial match anchors
- 3 topical/related anchors
- 2 branded or generic anchors ("click here" sparingly)
```

## Content Production at Scale Prompts

### Prompt 6: Cluster Content Brief Template

```
Create a content brief for a cluster page:

Pillar topic: "[main topic]"
This cluster page: "[specific subtopic]"
Target keyword: "[keyword]"
Search intent: [informational / navigational / commercial / transactional]
Target word count: [800–1,500 for cluster pages]

Brief includes:
1. Audience and purpose statement
2. Keyword placement map (title / H1 / H2s / intro / conclusion)
3. Complete outline with H2s and H3s
4. Key points per section (what to cover, not how to write it)
5. Internal links to include (to pillar + related cluster pages)
6. External sources to cite
7. Target featured snippet (if applicable)
8. Differentiation angle (why my version will be better)
```

## Frequently Asked Questions

### How many cluster pages do I need to build topic authority?

There's no magic number, but a cluster with a strong pillar and 10–15 well-interlinked cluster pages typically starts showing topical authority signals within 6–12 months. Quality and internal linking depth matter more than raw quantity.

### Should I build all cluster content before publishing, or publish as I go?

Publish the pillar page first, then build cluster pages incrementally and update internal links each time. Don't wait until the full cluster is complete — getting early pages indexed and earning links gives you a head start. Use the internal linking audit (Prompt 4) to ensure every new page gets properly linked.

### How long should a pillar page be?

For competitive topics: 3,000–6,000 words. For less competitive niches: 2,000–3,500 words. Use Prompt 2 to build the blueprint first — let the number of subtopics determine the length organically, rather than hitting a word count target artificially.

### How do I prevent cluster pages from competing with each other (keyword cannibalization)?

Ensure each cluster page targets a meaningfully different keyword with different intent. Use Prompt 1 to map out the cluster upfront — if two pages have nearly identical target keywords, merge them into one comprehensive page. Keyword cannibalization usually happens from poor planning, not over-production.

### How often should I update my pillar page?

Review every 6 months. Add new cluster pages as links when published. Update statistics and examples when they become outdated. A pillar page that grows over time signals freshness to Google and compounds its authority. Set a calendar reminder to audit your top pillar pages twice a year.
