Every student deserves access to learning. These prompts help educators design inclusive materials, adapt existing content for diverse needs, and write the documentation that supports students with disabilities — faster and with more consistency.

## Differentiation Prompts

### Prompt 1: Universal Design for Learning Adapter

```
Adapt this lesson using Universal Design for Learning (UDL) principles:

Original lesson: [describe your standard lesson]
Subject: [subject]
Grade: [grade level]
Diverse needs in my class: [describe — autism spectrum / ADHD / dyslexia / visual impairment / ELL / gifted / etc.]

Adapt using UDL's three principles:

MULTIPLE MEANS OF REPRESENTATION (how content is presented):
- Visual: [visual supports to add]
- Auditory: [audio/verbal supports]
- Kinesthetic/tactile: [hands-on options]
- Text support: [simplified / highlighted / annotated version]

MULTIPLE MEANS OF ACTION AND EXPRESSION (how students show learning):
- Writing alternative: [for students who struggle with writing]
- Verbal alternative: [oral response options]
- Technology option: [digital tool alternatives]

MULTIPLE MEANS OF ENGAGEMENT (how to motivate):
- Interest connections: [tie to student interests]
- Self-regulation supports: [structured choices / break options]
- Social learning option: [partner or group alternatives]
```

### Prompt 2: IEP Goal Writer

```
Write IEP goals for a student with:

Disability category: [learning disability / autism / intellectual disability / speech-language / other health impairment / etc.]
Student age/grade: [X years old, Xth grade]
Current performance level: [describe what the student can currently do]
Target area: [academic / communication / social / behavioral / functional / life skills]
Annual goal timeframe: [one school year]

Write 3 SMART IEP goals for this area:

Each goal includes:
- Annual goal statement: [Student name] will [observable behavior] [conditions] [criteria/measurement]
- Measurement method: [how to track progress — frequency count / rubric / percent accuracy / duration]
- Reporting schedule: [quarterly / trimester]
- Short-term objectives (2–3 steps toward the annual goal)
- Recommended supports and accommodations

Use behavioral and observable language — no "will understand" or "will appreciate."
```

### Prompt 3: Accessible Material Creator

```
Create an accessible version of this material:

Original material: [paste text or describe the worksheet/handout]
Accessibility need: [dyslexia / low vision / cognitive disability / ELL / ADHD / etc.]

Adapt for [specific need]:

FOR DYSLEXIA:
- Simplify sentence structure
- Break into shorter paragraphs
- Add visual breaks
- Bold key terms
- Suggest dyslexia-friendly font (OpenDyslexic / Arial / Verdana)

FOR COGNITIVE DISABILITIES:
- Reduce reading level to [grade X]
- Replace complex vocabulary with simple words
- Add visual symbol suggestions [describe each]
- Break multi-step instructions into single steps
- Add "I can" success criteria statements

FOR ADHD:
- Break into shorter sections with clear stopping points
- Add checkboxes for each step
- Include visual timers or time estimates
- Reduce visual clutter
- Highlight essential information only
```

## Behavior Support Prompts

### Prompt 4: Behavior Support Plan Framework

```
Create a behavior support plan framework for:

Student profile: [age, grade, disability if any]
Target behavior: [the behavior to address — describe specifically]
Function of behavior: [attention-seeking / escape / sensory / tangible item]
Current triggers identified: [what precedes the behavior]
Current consequences: [what happens after]

Framework includes:
1. Operational definition (measurable description of the behavior)
2. Antecedent interventions (prevent the trigger)
3. Teaching replacement behavior (what they should do instead)
4. Reinforcement strategies
5. Response strategies (when the behavior occurs anyway)
6. Data collection method
7. Generalization plan

Note: this framework should be developed with the full team (special ed teacher, parents, school psychologist) and the student where appropriate.
```

## Frequently Asked Questions

### Can ChatGPT write legally compliant IEP documents?

ChatGPT can draft goal language and frameworks that follow best practices, but IEP documents are legal documents governed by IDEA (in the US) and must be developed by the IEP team, reviewed by special education staff, and comply with your specific school district's requirements. Use ChatGPT to draft, then review with the special education coordinator or case manager before finalizing.

### What UDL supports benefit all students, not just those with disabilities?

All of them, actually — that's the principle behind UDL. Visual supports, chunked instructions, multiple response modes, and clear success criteria benefit every learner, including those without identified disabilities. The students with the most complex needs make visible what all students benefit from.

### How do I use ChatGPT to differentiate instruction without creating 30 different versions of everything?

Create 3 versions: below grade level (modified), at grade level (standard), and above grade level (extended). Use Prompt 1's framework to vary representation, expression, and engagement, not necessarily the core content. Many accommodations (visual supports, simplified directions) can be offered to the whole class without singling anyone out.

### What's the most time-saving ChatGPT application for special education teachers?

IEP goal writing (Prompt 2). Special education teachers write dozens of IEP goals per year, each requiring specific, measurable language aligned to the student's present levels. ChatGPT produces well-structured goal language in seconds that teachers then personalize. The time saved on goal writing can be redirected to direct student support.

### How do I ensure ChatGPT's adapted materials are culturally responsive?

Review all generated materials for cultural assumptions, language that centers one cultural perspective, and examples that may be unfamiliar or irrelevant to your student population. Ask ChatGPT to "review this material for cultural assumptions and suggest more culturally inclusive alternatives." Always apply your own cultural knowledge of your specific students and community.
